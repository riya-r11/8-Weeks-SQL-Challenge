# Case Study 2
## Pizza Runner

### Project Overview
This project is part of the **[8 Week SQL Challenge – Case Study #2: Pizza Runner](https://8weeksqlchallenge.com/case-study-2/)** created by Danny Ma.

The objective of this case study is to analyze a fictional pizza delivery business using **Microsoft SQL Server** and derive insights into customer orders, pizza preferences, delivery performance, ingredient optimization, and business profitability.

Through this project, I practiced writing SQL queries to solve business problems and translate raw data into meaningful insights.

### Business Objectives

The analysis focuses on answering business questions across the following areas:

- **Pizza Metrics**: Analyze order volumes, pizza types, customer orders, and ordering patterns.
- **Runner and Customer Experience**: Evaluate delivery success, preparation time, delivery duration, and average speed.
- **Ingredient Optimization**: Analyze standard ingredients, extras, exclusions, and topping usage.
- **Pricing and Ratings**: Calculate pizza revenue, additional charges, runner costs, and delivery ratings.
- **Database Design**: Design a ratings table and explore how the menu can be extended with new pizza types.

### Tools and Technologies

**Database**: Microsoft SQL Server
**SQL Concepts**: JOINs, CTEs, aggregate functions, CASE expressions, window functions, subqueries, string manipulation, and data cleaning.

1. Visit the official [Pizza Runner](https://8weeksqlchallenge.com/case-study-2/) case study to review the business context and dataset.
